# apg-playwright

Conversion of the [Patterns](https://www.w3.org/WAI/ARIA/apg/patterns/) within the [ARIA Authoring Practices Guide](https://www.w3.org/WAI/ARIA/apg/) into sample spec files that can be used to test the accessibility of common widgets in [Playwright](https://playwright.dev/)

Each of these spec files are based off our [apg-gherkin feature descriptions](https://github.com/AFixt/apg-gherkin/)
